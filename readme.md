
# Programmazione ad Oggetti – Esercitazioni Java

Questa repository contiene le esercitazioni e i laboratori svolti durante il corso di **Programmazione ad Oggetti** presso il Politecnico di Torino.

## 🎯 Obiettivi del corso

Il corso introduce i principi fondamentali della programmazione orientata agli oggetti (OOP) attraverso il linguaggio **Java**, con particolare attenzione a:

- Incapsulamento, ereditarietà e polimorfismo
- Interfacce e classi astratte
- Collezioni Java (`ArrayList`, `HashMap`, `Set`, ecc.)
- Eccezioni, input/output e serializzazione
- Design modulare e strutturato

## 📁 Contenuto della repository

- `src/` – Codice sorgente organizzato per esercitazione o pacchetto
- `test/` – Eventuali test o esercizi di verifica
- `README.md` – Questo file

> ⚠️ I testi ufficiali degli esercizi **non sono inclusi** per rispetto delle policy accademiche. Il codice è frutto del mio lavoro personale.

## 🛠️ Compilazione ed esecuzione

Questi progetti sono stati sviluppati in Java, compatibili con **Java 8+**.
